# Project Management

## Kanban Workflow

Pac-Man was developed collaboratively by **aeddiba** and **niboutta** using a
Kanban board created from the GitHub Projects template.

The board was used to:

- organize the project requirements into actionable tasks;
- assign work between both contributors;
- track tasks from backlog to in progress, review, and completed;
- prioritize bug fixes and required documentation; and
- monitor progress through implementation, testing, and packaging.

The project was divided into work covering the game loop, configuration
parsing, maze generation, gameplay entities, user-interface screens,
highscores, packaging, and quality checks.
